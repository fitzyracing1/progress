# Getting started

## Install

```
npm install @fitzyracing/progress
# or keep the old name:
npm install progress@npm:@fitzyracing/progress
```



## Usage

Same as upstream: `new ProgressBar(format, options)` with `.tick()`, `.interrupt()`, `.terminate()`. See the Readme "Usage", "Options" and "Tokens" sections, and `examples/`.

## Develop and test

```
npm install
npm test   # node --test test/progress.test.js
```
